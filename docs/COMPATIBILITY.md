# 验证记录

目标：仅小米 17 Pro Max 背屏；Android 15+；LSPosed classic API 82 或 Vector modern API 101。

## 0.1.32（2026-10-22）

- R8 Release 构建、算法单元测试及 APK 入口检查通过；未打包 Xposed 框架 API stubs。
- 已安装新包 `com.zephyr.rearmusic` 并启动设置页。新包的作用域启用和注入尚待用户切换验证。
- 白名单固定开启，设置页移除对应开关，状态简化为注入结果；补充模块介绍。
- 改包名后不会继承旧包配置，需要重新选择播放器、授权应用列表及启用两个作用域。

## 历次真机结果与限制

- 17 Pro Max 背屏 display 1 为 976×596，摄像头区域宽 296 px，律动几何按该机调整。
- 旧包历次验证过白名单放行、原生封面/歌名/歌手/控件显示，以及音乐页退出隐藏、返回显示。
- 原生音乐卡片负责媒体内容；模块仅提取封面色并绘制摄像头区域律动。
- FFT 采样使用系统 Visualizer，设备最高回调率为 20 Hz；动画目标约每 320 ms 更新，13 阶幅度不等于与 Flip 使用相同音源。
- 系统音量为零时采样静音，不支持静音下继续有效律动。
- 息屏持续刷新经过多次修复；0.1.31 将关闭息屏律动时的隐藏阈值缩短到进入 Doze 后 300 ms，叠加轮询和淡出后实际时间更长，最终物理屏幕效果待复测。
- 升级后 LSPosed 可能缓存旧 APK 路径，需重新启用模块或重启手机。

构建、安装成功不代表所有固件和播放器均已通过真机测试。
